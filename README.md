# Measured DJ room

[Open the walkthrough](https://frompaulxam-gif.github.io/measured-dj-room/walkthrough/) · [View the PDF](https://frompaulxam-gif.github.io/measured-dj-room/room-before-and-after.pdf)

Current and proposed room concepts. Move with W A S D and drag to look around; hold Shift to move faster. Plants and pots can be passed through for easier exploration. Walls and fixed furniture remain solid. FOV starts at 80° and is adjustable. The PDF compares references, actual Blender renders and clearly labelled GPT appearance enhancements.

The model follows the supplied 100 × 133 inch footprint, with the one-inch outline discrepancy reconciled as described in the dimensions panel. Door, window and ceiling measurements remain assumptions. GPT images are visual studies, not measurement sources.

Runtime geometry and textures are included here; the editable Blender project and authoring source remain in the maintained local project.
